## Exact local startup — macOS and Windows

Install Git, Node.js 24 LTS (Node 22+ is supported for verification) and current desktop Google Chrome. Use a separate clone and a writable disposable folder. The following commands work in macOS Terminal and Windows PowerShell, one command per line. On Windows, use `npm.cmd` instead of `npm` if PowerShell blocks npm.ps1; no execution-policy change is needed.

```sh
git clone --branch feature/v1.5-approved-enhancements https://github.com/anonapps/PM-POC.git PM-POC-v15-acceptance
cd PM-POC-v15-acceptance
git fetch origin refs/heads/feature/v1.5-approved-enhancements
git switch --detach d46b4f0ae8c6d94aaaca0cf73ea2314880a65f9f
git rev-parse HEAD
node --version
npm ci
npm run build
npm run start -- --hostname 127.0.0.1 --port 3000
```

Open **http://127.0.0.1:3000** in Chrome; leave the terminal running. Stop with Ctrl+C when finished. This pins the Search/Filter remediation runtime `d46b4f0ae8c6d94aaaca0cf73ea2314880a65f9f`; the earlier dafe9ea candidate evidence does not validate these UI corrections. Use the current readiness register for this runtime’s test results. Later checklist-only commits do not change that runtime. Do not substitute a newer runtime without reviewing its evidence. If port 3000 is occupied, use `--port 3001` and open the matching localhost URL. This runs locally and does not deploy or update production.

## Numbered acceptance run — repeat on both computers

Mark Pass/Fail/Blocked with evidence for each step and each detailed matrix row above. None is certified by the Linux run.

1. Launch Chrome, confirm 1.5.0-rc.1, create **ARGOS v15 disposable acceptance** as a new `.pmp` in a disposable folder. Check mandatory errors and valid dates. Add two People, two Streams, a parent/child Task pair, a Project-wide Task, one shared Milestone, one Risk and one Decision with fictional data. Enable audit recording before edit checks.
2. Exercise New/Open/Close and Save/Save As in File Information. Cancel pickers. With a pending edit, verify Save/Discard/Cancel, same-file Discard and failure recovery using the separate native checklist. Never overwrite original project files.
3. In all eight shared toolbar modules, type live search, combine multiple values and categories, clear, navigate away/back, and check reset/active state. Test Escape, outside dismissal and focus return.
4. Repeatedly create records in all six record modules with mandatory inputs only. Check errors, notification, cleared fields/filters, first-field focus and Enter. Test Cancel and navigation Stay/Discard with a populated draft.
5. Search predictive owners/scopes/dependencies/context by name and human ID. Use arrows, Enter, Tab/Shift+Tab and Escape. Filter a selected multi-value choice out and back; confirm it survives and query clears on close.
6. Edit names, accented text, notes and descriptions. Blur, Undo and Redo; verify one edit, preserved later casing/whitespace, Cancel protection and no event on unchanged blur. Inspect Audit Log recording on/off, sort/search and CSV export.
7. Review Gantt at all zooms, footer/range/Previous/Next/Jump to today, hierarchy, crowded labels, dependencies, Today body line, quick-edit Save/Cancel and scrolling. Verify the 1/7/14-day increments and that the footer never covers the last row or dependency information. Compare Tube Map lanes/shared Milestones, Monday/week labels, paging, sticky axis, Today marker and quick edits. Check independent Hide Empty Streams and single controls.
8. Review Risk matrix and context/actions; Decision context and retained Task/Risk links. Save/Cancel and Ctrl/Cmd+Enter, Undo/Redo and reopen must preserve relationships.
9. Confirm search is centred against page content across all ten modules regardless of titles, Show Deleted/Add/actions or active filters, including the narrow second-row fallback. Compare expanded/collapsed sidebar positions at 1440, 1080 and 768 widths and normal/OS-scaled displays. Check content scrolling, sticky controls, crowded layouts, hover/focus tooltips and narrow ALL pill. Complete every flow once using keyboard only.
10. Open the bundled manual from File Information and confirm candidate labelling/version and readable PDF. Save, Close, reopen and compare data/audit. Record discrepancies, screenshots and final assessment; complete the separate native compatibility checklist on backed-up legacy files.
