## Regenerate current downloads

Install Pandoc, XeLaTeX and the DejaVu Sans/DejaVu Sans Mono fonts locally, then run from the repository root:

```bash
bash scripts/build-v17-manual.sh
```

The single source is `docs/V1.7_UI_REFERENCE.md`. The script builds `public/manuals/1.7/ARGOS_PM_UI_REFERENCE.pdf`, copies it to `docs/ARGOS_PM_UI_REFERENCE.pdf`, and generates `docs/ARGOS_PM_UI_REFERENCE.docx`. Check the PDF contents/layout and parity after editing the source. Archived v1.4 binaries and versioned v1.5/v1.6 PDFs are not regenerated by this command.
