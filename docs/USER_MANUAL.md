# ARGOS PM v1.7 — user manual

Use the [complete manual](V1.7_UI_REFERENCE.md), [downloadable PDF](ARGOS_PM_UI_REFERENCE.pdf) or [editable Word copy](ARGOS_PM_UI_REFERENCE.docx). In the app choose **Settings → UI Reference Manual**. This is the current v1.7 main-branch documentation, updated 12 November 2026 after PR #34; a tagged release is a separate action.

## First project

1. [Install and start locally](../README.md#quick-start--first-run-macos--terminal), then open desktop Chrome at the printed local URL.
2. Choose New Project, complete Name/Start date/Status, then Choose File & Create and save the `.pmp` file. Or use Open Project for an existing file.
3. Use Settings → Project Details for project metadata and Show progress information. Check the sidebar save dot; reveal Save Now/Undo/Redo with Alt+Shift+T or the top-edge hover strip.
4. Add People and Streams, then Tasks and Milestones. Use the normal inline fields, scope/owner selectors and creation drawers.
5. Review Gantt/Tube Map, create a named Baseline, and compare the live schedule without changing history. Use Extended Gantt → Critical Path Analysis for calculated dates/float; calculations never automatically reschedule planned work.
6. Track Risk actions and Decisions; use Search and Warnings to open the exact related record. Save and keep separate backups of important files.
