Extended Mode proposal — compact spacing is confined to these two panes.

Split and scrolling
Start at approximately 55/45 of the remaining content height. Drag the horizontal separator or use its keyboard controls. Each pane has its own vertical scrollbar; the chart date headings, Tasks headings and chart date footer stay visible. Minimum pane height 200px; smaller windows permit page vertical scrolling.

Existing interactions
Chart quick edits, stream navigation, collapse/expand, zoom, search/filter and dependency controls remain. Tasks keeps all fields, hierarchy, sort/filter, multi-selection, deletion, predictive selectors, creation and editing. At narrow widths, fields wrap vertically into labelled groups.

Scope of approval
Approve this layout and interaction proposal before implementation. Compact row spacing applies only inside Extended Mode. Standalone Tasks and Simple Gantt keep their standard layout. Baseline selection is shared; overlay and dependency visibility are independent view controls. No automatic scheduling.
