# v1.6 Gantt approval mockup

`extended-mode-mockup.html` is a self-contained presentation prototype with representative Atlas Software Delivery data and explicit design notes. It contains no application store, feature toggle implementation, file access or production integration. `simple-mode.png` and `extended-mode.png` were captured from this prototype in Chromium at a 1440px viewport.

These images propose layout, compact treatment, toggle placement, date footer, baseline/dependency controls and a resize separator. They are design-reference images rather than implementation evidence. The owner subsequently approved the revised mockup conditional on exact standalone Tasks panel equivalence; the implementation and actual screenshots are recorded separately in `docs/V1.6_PROGRESS.md` and `docs/media/v16-extended/`.

Revision: `extended-add-task.png` shows the full-height page-level Create Task panel over the project header and both panes. All three screenshots now use centered Search fields and the existing status palette. Chromium measurements verify equal search centers in Simple/Extended/creation views and a creation panel aligned to the full screen frame. That revision changed only presentation artifacts and requirements; the subsequent approval and implementation are recorded in the phase report.
