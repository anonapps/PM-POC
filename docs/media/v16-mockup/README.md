# v1.6 Gantt approval mockup

`extended-mode-mockup.html` is a self-contained presentation prototype with representative Atlas Software Delivery data and explicit design notes. It contains no application store, feature toggle implementation, file access or production integration. `simple-mode.png` and `extended-mode.png` were captured from this prototype in Chromium at a 1440px viewport.

These images propose layout, compact treatment, toggle placement, date footer, baseline/dependency controls and a resize separator. They do not establish that Extended Mode is implemented or approved. The application remains Simple Mode only. Review `docs/V1.6_EXTENDED_MODE_MOCKUP.md` and obtain explicit owner approval before coding the feature.
