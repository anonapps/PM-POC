# ARGOS PM v1.5 interaction reference — draft source

This source describes the implemented v1.5 controls on the feature branch. It is not a published manual or a claim of release readiness. The full illustrated manual, PDF asset and desktop acceptance remain release gates.

## Search and filters

Search, Streams, People, Tasks, Milestones, Risk Log, Decision Log and Warnings share one Search / Filter icon button. Open it to type a live query and choose filters. Matching ignores case and accents and searches descriptive fields as well as displayed columns. Several terms must all match the same record; their order does not matter.

Selections within one category match any selected value; different categories must all match. Risk Matrix cells set the same Level filter shown in the popover. Changes take effect immediately. The Active indicator remains visible after closing the popover. Clear search and filters resets both. Escape closes the popover and restores focus to its button; clicking outside also closes it. Navigating to another module resets query, filters and Show Deleted.

## Creating records

Show Deleted appears before Add. Add opens an inline form containing only required fields, marked with an asterisk. Search / Filter stays visible and disabled until creation is cancelled. Tasks, People, Streams and Risks require a name/title. Milestones and Decisions also require a date. Missing or invalid values show errors beneath their fields.

Enter submits a single-line creation form. Success briefly announces creation, clears query/filters/Show Deleted, clears the inputs and focuses the first required field. The form stays open for another record. Cancel discards its contents. Navigation from a populated form asks whether to discard the draft or stay.

Optional Task scope, owners and predecessors are edited after creation through row controls. Milestone scope/owners/dependencies remain available in their row. Risk and Decision Edit context controls open drafts for optional notes and relationships. Cancel discards context edits; Save commits them together. Ctrl/Cmd+Enter saves multiline context.

## Predictive lists

Owner, scope and context lists search names and human-readable IDs, such as PERSON-001 and STREAM-003. Open a list, type in its search row, use arrows to focus results and Enter to choose. Tab retains normal keyboard navigation. Escape closes and returns focus to the disclosure. Closing clears its search query.

Multi-select relationships retain selections when a query hides them. Enter toggles the focused result; it does not submit a surrounding form. Fixed short controls, such as status, keep their normal native selection behaviour.

## Project files and release status

The local `.pmp` format and existing project data remain authoritative. No conversion to `.mpp`, schema migration or external service is introduced by these controls. Browser automation mocks file-picker consent; native file access and supported-platform checks still require manual review. No v1.5 publication is authorised by this draft.
