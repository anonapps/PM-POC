# ARGOS PM v1.5 — Watch Video

[Watch Video](https://anonapps.github.io/PM-POC/videos/latest/)

The current Atlas Software Delivery recording is 78 seconds, 1920×1080, 30 fps and silent H.264. Its permanent version page is `/PM-POC/videos/1.5.0/`; the `latest` entry advances through `docs/media/demo-catalog.json` when future release videos are added. Older version pages remain available.

The video-only GitHub Pages site uses a native player with playback, seek and fullscreen controls. It has no application runtime, analytics, external scripts or advertised file-transfer links. Native controls hide the transfer menu where supported; public video cannot technically be made unsaveable.

One-time repository setup: Settings → Pages → Source → GitHub Actions. The GitHub connector cannot change this administrative setting; GitHub's official configure-pages action also requires a separate administration-capable token to enable a site, so the workflow deliberately does not attempt enablement. No token needs to be shared.

Local player verification and published-player verification are distinct. Do not mark the published check passed while Pages is disabled or a remote player has not advanced video time successfully.
