## Known limits

- Extended Mode is implemented following the recorded conditional approval. This does not authorize merging or publishing v1.6.
- Native Windows/macOS file-picker consent and physical-machine visual acceptance were not executed in this Linux environment. Browser file tests use disposable in-memory adapters and decode the actual generated PMP bytes.
- Existing chart connector support is preserved: Gantt renders supported FS task connectors; Tube Map renders milestone connections. The inspection workspace preserves all supported relationship types.
- Baseline selection is session-only; deleted/offscreen historical entities remain fully available through comparison rather than fabricated live chart rows.
- No cloud collaboration, scheduling engine, critical path, what-if or milestone trend visualization was added.
