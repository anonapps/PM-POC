## Required story

1. Create a new software delivery project. Leave the option to show progress percentages unchecked.
2. Create four streams: Discovery and Design, Application Development, Integrations, Quality and Release.
3. Create five people.
4. Create two tasks per stream (eight total), covering all supported statuses and a variety of dependencies and owners.
5. Create milestones in the following distribution: two for Discovery and Design, two for Application Development, five for Integrations, none for Quality and Release.
6. On Tube Map, quick-edit a milestone, navigate the date window and use and clear a filter.
7. Create two risks: one Low/Medium (or Medium/Low) and one High/High, with comments, context and mitigation actions.
8. Create two decisions and populate every available field.
9. Cause a real date/dependency warning, open it on the Warnings page, navigate to the affected record, correct it and confirm the warning clears.
10. Open File Information, expand the Audit Log, scroll through it, save the project and close it. End on the closed-project view.
