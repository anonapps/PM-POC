## Reproduce

Run the production application, then `CAPTURE_ATLAS_DEMO=1 DEMO_OUTPUT_DIR=/tmp/atlas E2E_BASE_URL=http://127.0.0.1:3000 CHROME_PATH=/usr/bin/chromium npm run test:layout -- --grep 'Atlas software'`. Render with `python3 scripts/render-v15-demo.py /tmp/atlas docs/media/argos-pm-demo-v1.5.0.mp4`. This rejects a video above 80 seconds and decodes the complete output before replacement. Build a fresh empty player directory with `node scripts/build-demo-site.mjs /tmp/atlas-site`; verify it with `CHROME_PATH=/usr/bin/chromium node e2e/verify-demo-site.mjs /tmp/atlas-site`.
