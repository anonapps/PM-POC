## File/data verification and limitations

The fixture is a fictional existing project loaded through the real PMP reader. Shown edits use actual forms and canonical commands. The browser's isolated adapter implements the existing File System Access interface and retains bytes written by the application; it is not a native permission dialog. The footer discloses the adapter throughout.

After saving/reopening, independent ZIP/JSON inspection and browser assertions confirm PMP **format 1/schema 2**, runtime **1.5.0**, 2 Streams, 2 People, 7 Tasks, 4 Milestones, 1 Risk, 1 Decision and 4 audit events. Explore launch ideas remains Tentative with Maya Chen and Product Design. Streams/Milestones/Risk data match the loaded fixture. No browser runtime errors occurred. Tentative retains its capability minimum 1.5.0-rc.1; the stable reader supports it.

This does not certify Windows/macOS OS consent, real disk permissions or physical failure recovery. The owner authorised merge/publication on 25 October 2026; those native checks remain explicitly unverified. No production deployment is part of the demo or GitHub release.

## Reproduce

Start the production build locally, then run the same permanent browser journey:

```sh
CAPTURE_V15_DEMO=1 DEMO_OUTPUT_DIR=/tmp/argos-v15-demo E2E_BASE_URL=http://127.0.0.1:3000 CHROME_PATH=/usr/bin/chromium npm run test:layout -- --grep 'v1.5 release journey'
python3 scripts/render-v15-demo.py /tmp/argos-v15-demo docs/media/argos-pm-60s-demo-v1.5.0.mp4
```

Capture needs Chrome/Chromium; rendering needs Python 3, FFmpeg/ffprobe and DejaVu Sans. The normal CI journey does not record or wait through reading holds. The renderer rejects incorrect duration, frame count, resolution or streams and fully decodes before accepting output. Exact bytes can vary with browser/encoder/font versions; provenance and technical checks must be regenerated, not copied.
