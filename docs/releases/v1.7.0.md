# ARGOS PM v1.7.0 — release candidate

**Prepared 1 November 2026. Unpublished: no merge to main, tag, release or deployment is implied.**

ARGOS PM v1.7 adds local Critical Path Analysis to the existing planning workspace. It retains the approved v1.6 UI, offline operation and canonical `.pmp` project data.

- Project-wide and per-stream analysis uses the full dependency graph, all four supported relationship types, inclusive calendar days, Project Start and same-day Finish-to-Start semantics. Linked milestones are zero-duration events. Calculations do not change planned dates.
- Reliable calculated dates, total/free float, critical-task counts and distinct maximal critical sequences are derived in memory. Incomplete data, cycles and schedule conflicts produce Partial results; provisional completion and unreliable values are explicit.
- Extended Gantt offers Tasks/Analysis tabs with keyboard navigation, a shared resizable divider, independent scrolling, searchable/filterable/sortable results, expandable details and shared Quick Edit. Tasks is the normal Extended default; Overview provides a direct Analysis shortcut.
- Analysis task selection reveals and highlights the corresponding Gantt row without moving the lower pane or changing search/status/sort settings. Collapsed streams are temporarily revealed; clearing selection restores collapse preferences. Stream disclosure accessibility matches the temporary display.
- Gantt/Tube Map Critical Path toggles are independent, default off and preserve status colors. Gantt includes Hide Unscheduled Tasks; both charts share compact filter spacing and retain their specific options.
- Linked milestone scheduling diagnostics are visible in related task details and reuse the deduplicated Warnings records. Missing, invalid and reversed task schedules share the same Unscheduled classification across calculations, analysis and filtering; correction is an explicit edit.
- Local CSV exports include active tasks in the calculation scope regardless of display filters. Calculation refresh/failure/Retry states do not interfere with file operations, Undo/Redo or audit history.

## Compatibility

PMP container format 1/schema 2, baseline snapshots and supported legacy project behavior are unchanged. No v1.7 technical migration or new minimum-reader requirement is added. Existing baseline-bearing files require at least v1.6 as before. Calculation caches, view selection and chart toggles are never persisted as task data. There are no new runtime dependencies or dependency upgrades.
