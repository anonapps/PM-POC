ARGOS PM v1.5.0 brings consistent creation, search and timeline workflows to the local-first project workspace.

- One full-field creation side panel for Streams, People, Tasks, Milestones, Risks and Decisions, with keyboard operation, stable validation and unsaved-draft protection.
- Centred shared Search / Filter controls, predictive selectors and anchored dropdowns.
- Task-only Tentative status, six muted Gantt colours, complete legends and combined status filters.
- Persistent Gantt navigation with existing zoom increments; Tube Map milestone filters, compact footer and corrected sticky scrolling.
- Collapsible Risk Matrix, aligned Risk/Decision context editors, task bulk selection and compact Overview cards.
- Save/Discard/Cancel recovery, optional Audit Log and version-matched bundled Markdown/PDF manual.

The attached one-minute silent demo contains actual v1.5 application footage with fictional data. It uses an isolated browser file-picker adapter; native OS consent is not demonstrated.

PMP format 1/schema 2 and legacy data remain supported. Files containing Tentative Tasks require a v1.5 reader; older task statuses are not silently changed. Back up real projects before cross-version testing. There is no `.mpp` conversion.

Windows/macOS native picker permissions and physical-machine acceptance are not certified by Linux/Chromium automation. Release publication is expressly authorised by the repository owner; it does not claim those checks passed. No production service is deployed by this release workflow.

See the repository's v1.5 release-readiness register, desktop/native acceptance guides and demo verification notes for evidence and remaining platform checks. Source archives are available below; the application runs locally with Node.js and Chrome.
