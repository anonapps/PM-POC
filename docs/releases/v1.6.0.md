# ARGOS PM v1.6.0

ARGOS PM v1.6 adds schedule history and dependency inspection to the local-first project workspace, with a consistent reusable UI foundation.

- **Schedule baselines:** keep multiple named immutable snapshots; compare historical/current dates, calendar-day variances, additions/removals and historical stream names. Create, rename and delete through the existing Undo/Redo history.
- **Planning views:** show optional baseline overlays/variance in Gantt and a separate date-aligned historical milestone strip in Tube Map. Extended Gantt combines a resizable chart and the real Tasks table with shared edits/history.
- **Dependencies:** inspect/filter/sort/edit existing cross-stream relationships with stable IDs and cycle/duplicate/endpoint validation. Warnings are informational and never change schedule dates automatically.
- **Clear relationship focus:** dotted grey connectors in both charts, one emphasized relationship at a time, connected-item focus and synchronized Hide dependencies filters.
- **Consistent UI:** compact matching chart footers, DD/MM axis dates, shared column headings, compact Baselines management, docked Dependencies information and the accepted narrow creation forms with visible submit/cancel actions.
- **Reusable assets:** a canonical compatibility token source, native action/field/choice compositions, an isolated real-component catalogue and documented usage/intentional variants. Existing fonts, semantic palettes and application behavior are preserved.

The version-matched v1.6 UI reference accompanies the source. Existing v1.5 demo footage remains explicitly historical; no new v1.6 video is claimed.

## Project compatibility

The `.pmp` project remains the self-contained source of truth. PMP container format 1/schema 2 and supported legacy projects remain compatible. Saves containing schedule baselines require a v1.6 reader; files without baselines retain their existing minimum-reader calculation. Keep backups of real projects before cross-version testing. There is no `.mpp` conversion.
